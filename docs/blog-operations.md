# 담담공방 운영 방식

운영자도 `/login`에서 아이디와 비밀번호로 로그인합니다. 상단의 **편집 모드**를 켜면 상품·게시글·공지·FAQ에 추가·수정 버튼이 나타납니다. 새로고침과 로그인 시 편집 모드는 꺼집니다. 일반 회원에게 운영 버튼이 표시되지 않으며 서버가 모든 운영 요청의 권한을 확인합니다.

| 작업 | 위치 |
|---|---|
| 상품·옵션·가격·사진·공개 상태 | `/products`, 상품 상세 |
| 재고 수량 및 변동 기록 | 상품 수정의 재고 조정·기록 |
| 게시글과 댓글 관리 | `/posts`, 글 상세, 글쓰기/수정 |
| 공지·FAQ | `/notices`, `/faq` |
| 오늘 할 일(입금 확인 대기·발송 준비·매출·재고 부족) | `/mypage` |
| 전체 주문 처리(상태별 보기·검색·입금 확인) | `/mypage/orders` |
| 회원 조회·댓글 제한 | `/mypage/members` |
| 입금 계좌·사업자 정보·고객센터 연락처 | `/mypage/settings` |
| 운영 기록 | `/mypage/history` |
| 비밀번호 변경 | `/mypage/account` |

기존 `/admin/*`와 `/community`는 새 페이지로 이동하고 `/return-policy`는 `/exchange-policy`(교환·반품 안내)로 이동합니다. 홈페이지 문구와 사진 편집은 포함하지 않습니다.

## 사업자 정보 표시

전자상거래법에 따라 모든 화면 바닥글에 상호·대표자·사업자등록번호·통신판매업 신고번호·사업장 주소와 고객센터 연락처를 표시해야 합니다. 이 값은 `/mypage/settings`의 **사업자 정보**·**고객센터**에서 입력하며, 입력한 항목만 바닥글·약관·FAQ에 나타납니다. 운영 전에 반드시 모두 입력합니다.

## 게시글 작성

글쓰기에서 제목과 본문을 입력하고, 사진을 도구막대·붙여넣기·끌어넣기로 추가합니다. JPG·PNG·WebP를 장당 5MB, 글당 20장까지 사용할 수 있습니다. 사진 아래에서 설명·크기·정렬·순서를 바꿀 수 있으며 본문 사진 중 대표 이미지를 고릅니다. 카테고리 추가·이름 변경·삭제와 태그 입력도 글쓰기 화면에서 합니다.

입력이 2초 동안 멈추면 서버에 초안을 저장합니다. 사용자·게시글별 브라우저 복구 초안도 보관하며, 미저장 내용이 있으면 재접속 시 복구할 수 있습니다. 공개 글의 초안을 수정해도 독자는 마지막 발행본을 계속 봅니다. 미리보기 후 **발행 / 발행본 업데이트**를 눌러 공개 내용을 갱신합니다.

저장이나 사진 업로드가 실패하면 발행할 수 없습니다. 다른 화면에서 먼저 수정한 경우 자동저장을 멈추고 현재 내용을 보관합니다. 내용을 복사하거나 서버 버전을 다시 불러와 해결합니다. 비공개 글과 임시글, 미발행 사진은 일반 방문자가 볼 수 없습니다. 공지와 FAQ는 같은 에디터를 사용하며 등록·수정 버튼으로 명시적으로 저장합니다.

## 계정과 주문

가입은 아이디·비밀번호·비밀번호 확인 및 필수 약관 동의만 받습니다. 아이디는 영문·숫자·밑줄 4~20자, 대소문자를 구분하지 않습니다. 비밀번호는 12~128자이며 Argon2id로 저장합니다. 이메일·소셜 로그인·자동 비밀번호 찾기는 제공하지 않습니다.

주문은 이름·전화번호·배송지와 실제 상품 옵션으로 생성하며 서버가 가격과 재고를 확인합니다. 고객은 결제 대기 주문을 취소할 수 있고 재고가 함께 복원됩니다. 운영자는 내 계정에서 주문 상태와 이력을 관리합니다. 무통장입금은 입금 확인 후 운영자가 처리하며 계좌 안내는 운영 설정에서 저장합니다. 결제 수단은 무통장입금 하나이며 입금 확인·환불은 운영자가 주문 상태로 기록합니다.

초기 운영자 ID는 보존하며 아이디는 `admin`입니다. 비밀번호는 `.env`의 `SEED_ADMIN_PASSWORD` 또는 배포 비밀 설정으로 주입합니다. 원본 비밀번호와 고객 계정은 승계하지 않습니다.
